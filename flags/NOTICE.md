# Flag assets

Circular flag SVGs vendored from **circle-flags** by HatScripts
(https://github.com/HatScripts/circle-flags), MIT-licensed.

Self-hosted here (no external CDN) so the bracket stays free, offline-capable,
and host-neutral per the board's EU hosting constraint (WOR-10/WOR-11).

Filenames are ISO 3166-1 alpha-2 codes (e.g. `fr.svg`), except England which
uses the subdivision code `gb-eng.svg`. The team-code → filename map lives in
`src/data/flags.ts`.
